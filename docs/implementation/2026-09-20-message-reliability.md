# 群消息可靠性实现与验证

## 已实现

- 插入顺序使用 `space_sequence`，修改和删除使用事务提交顺序的 `sync_sequence`。新客户端历史分页与展示顺序一致；旧接口保留。旧缓存只有消息 ID 时，v3 接口从该 ID 解析序号，不依赖可能倒退的消息时间。
- 已读位置单调推进；列表、已读回执、同步和历史遵守相同的异宠静音过滤。较早的已读请求不能清除后来到达的新消息。
- 发送队列按账号生命周期隔离。退出时旧网络请求不再删除、重试或失败标记新登录的消息；同账号再次登录不等待旧悬挂请求。
- 群页面的历史、成员、邀请、图片和发送操作在响应写回前检查账号、群和权限生命周期。离群或切换账号后，旧响应不能恢复受限内容。
- 恢复缓存、重连和返回前台重新核查已加载消息 ID 的可见性；权限复核与增量同步合并执行，避免覆盖待发送消息。
- 同账号同群的缓存实例共用写入锁和生命周期版本。撤权等待旧写入结束后清除数据，旧页面不能重新写入。退出账号清理建立等待屏障，新登录缓存等待旧磁盘扫描结束，避免被误删。
