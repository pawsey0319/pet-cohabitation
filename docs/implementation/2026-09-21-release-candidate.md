## 本轮可体验的变化

1. 群头像缓存复用、批量更新，异宠群回复使用本体头像；未读按消息序号推进，旧消息不会因迟到刷新恢复红点。
2. 发送先显示本地消息，服务端入库即结束发送状态；队列跨页面保留，AI 等待独立呈现，提交后继续输入的草稿保留。
3. 消息、异宠、事项、我的分工整理；记忆、成长、性格和桌宠从异宠入口进入，群功能从对应群工具进入。
4. 系统桌宠默认关闭。Android 在“异宠 → 桌宠”主动授权后开启，支持拖动、隐藏、恢复和小窗聊天。形象需先在成长页完成透明预览确认；缺少已确认透明图时保留提示，不用有底色原图冒充透明。
5. 主人身份依据账号绑定，限定的身份问句直接引用正确昵称；同名和冒认按账号区分。
6. 性格从有来源的表达逐渐积累；单次表达不会直接改变长期性格。群关系理解使用每只异宠单独的全员授权，可查看依据、纠正和撤回。
