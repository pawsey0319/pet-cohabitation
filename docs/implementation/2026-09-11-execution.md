## 当前结论

T01–T09、T11–T13 的代码已经整合到安卓工作区，各模块已完成一轮本地验证。前次 Android 1.0.5 候选 APK 已完整构建并通过配置及签名验证；本次用户五项手机反馈已修复，完成用户指定 4.6 的独立复查，Android 1.0.6 已构建并通过 21 项包内配置、官方签名和新增界面内容核验，直接提供 APK。详见 [五项反馈修复](2026-09-14-mobile-feedback-fixes.md)。**云端已新增应用 17 项迁移（累计 34 项至 018）、发布 32 个兼容函数并启用 5 个新调度。业务接口 41 项、真实对话 11 项、真实定时提醒 21 项检查通过。** 手机完整验收和 7 天试用仍待完成；真实透明 worker 已启动，原缺失身体的样例修复且本地/云端完整预览批准链路通过，其他形象质量仍须逐图检查；图片理解与原图编辑验证开关保持关闭。详见 [云端发布记录](2026-09-14-cloud-release.md)。

当前交付版本是 Android **1.0.7 / versionCode 8 / preview / runtime 1.0.7**，含私聊群消息查询提速和连接中断恢复；实际 APK 配置、内容及同证书签名已核对。用户确认直接分发 APK，不上架 Google Play；手机品牌不是继续开发、构建或复查的前置条件。通知仍需在目标设备验证实际服务能力、权限与后台行为。已发布的 1.0.4 保持兼容路径，不能接收依赖本轮新增原生能力的 OTA。

## 已处理的集成问题

- 私聊图片附件在真实发送分支接入独立图片理解适配器，禁止顺带执行事项工具或自动提取记忆；按同一请求绑定文字、图片版本和摘要。
- 发送时只清除本次草稿，保留后来输入；账号切换停止流、语音、队列及旧结果。群消息已读只使用服务器确认后的消息 ID。
- 消息管家只处理有明确范围的群资料，个人记忆不进入载荷。代发先保存私人预览，确认事务生成真实消息与署名，不依赖模型宣称成功。
- 群工作台安排复用同一个事项编辑器与详情；新草案不再落入另一套旧提案数据，提醒明确区分共同安排与只提醒本人。
- 导出按稳定唯一键完整分页；清理过程保留已发布的共享协作记录。来源排除传播至搜索、接续、回顾、在途文本与派生图片说明。
- 云端维护使用有界租约、重试和路径墓碑，防止清理旧图时删除新引用。新增注销围栏兼容旧客户端及数据库先行升级窗口。
- Expo SDK 已对齐到 57.0.21，显式使用 SDK 配套的 Reanimated 4.5.1 / Worklets 0.10.1，补齐 expo-system-ui；Doctor 21 项全部通过。

## 环境与协作

- 主工作区：`.worktrees/agent-workbench-pet-onboarding`。保留已有改动，不重置现有数据库或其他任务文件。
- 隔离主库 `android-companion-validation` 用于模块回归；独立 `android-final-validation` 用于完整迁移链及图片传输验证。合成账号与数据在结束后清理。
- 初始本机 Kotlin 编译因没有 Java/Android SDK 退出 9009；现由 EAS 执行完整构建。另在忽略目录准备了经过来源校验的独立 JRE 和官方 apksigner，仅用于签名验证，没有修改全局 Java 配置或安装完整 SDK。
- 主负责人整合共享类型、迁移、私聊/群聊、验证与发布；三名执行子 agent 分别负责头像/原生/图片、事项/协作、提醒/记忆/维护。
- Grok 通过用户指定模型的外部调用参与模块建议，不是原生子 agent 型号。此前 300 秒超时及中止的检查均不算通过。用户本轮再次指定 Grok 4.6 后，以完整 ID `grok-4.6-high` 完成约 331 秒的限定范围复查，网关返回规范名 `grok-4.6`；主负责人核验 5 项意见、采纳 3 项并修复，另 2 项以实际接口并发/幂等证据判定未复现。后续修复已完成本地核验，没有声称 Grok 再次审核了修复后代码。详见 [复查与处理](2026-09-14-grok-review-resolution.md)。真实图片输入探测属于另一次明确授权的调用。
- 模型业务版本从配置读取；运行指标只记录耗时、错误码和状态，不记录真实私人正文、图片或记忆。
