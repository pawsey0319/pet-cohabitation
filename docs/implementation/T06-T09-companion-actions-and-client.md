# T06 陪伴工具与 T09 客户端正确性

2026-09-11。记录实现证据及当前验收边界，不代表部署或整个阶段完成。

## T06 实现

- `companionActions.ts` 为当前用户表达提供结构化事项/提醒规划。普通聊天不增加模型分类调用；候选判断仅用于路由，个人明确命令仍经过结构化规划与权限验证。愿望只给可编辑建议，群安排由本人预览确认后发布，负责人仍需接受。
- `007_companion_actions` 持久保存计划、确认决定和真实事务回执。任务与关联提醒在同一事务创建，失败不留半成品；重复确认复用回执。停止回答不撤销已写入事项，未执行的自动动作检查停止标记。卡片提供编辑、取消和事项详情入口。
- 新 `013_companion_clarifications` 保存单个待补全问题，绑定本人、异宠、话题、记忆版本、全部来源正文摘要和 20 分钟有效期。后续答案只能填写所问字段；其他字段、动作、范围及权限不由补全模型改变。换话题、来源变化、忘记、过期后停止接续。全部派生来源纳入排除传播。
- `WorkItemsPanel` 已接 `ReminderManager`，个人及已确认群事项都只为本人创建提醒；截止时间不自动创建提醒。
- 导出采用稳定分页，关联子表按批查询；私人删除先建立账号删除标记，服务端写入与图片上传受相同标记约束。已确认群记录保留。

## T09 客户端修复与证据

- 发送队列先持久化不可变请求再发送；按序处理，失败阻断后续，同 ID 重试。页面离开返回 `QueuePaused` 时保留队列，新页面回调可以继续。退出在等待本地写入或网络期间都同步停用队列，迟到返回不恢复缓存或发送后继消息。
- 搜索每个账号和全部筛选条件绑定独立请求代次，改变类型、日期、状态、群范围立即隐藏旧结果且解除等待。旧请求不能覆盖新查询。成员权限、忘记依据及事项变化实时清空结果，页面焦点或 App 状态变化重新要求查询；分页按实际取回行数前进，显示按类型和 ID 去重。
- `npm test -- --runInBand src/__tests__/privateSendQueue.test.ts src/search/__tests__/UnifiedSearch.test.tsx`：2 套 15 项通过。队列 8 项；搜索 7 项。合并事项测试复跑时共 4 套 26 项通过；全仓 `npm run typecheck` 通过。

## 交付边界

- 真实安卓页面、断网重开、多账号设备、原生通知投递必须另有真机记录。
- 群消息读取由主集成的安全管家查询分支负责；本工具规划器没有获取全量个人记忆或旧会话。
