## 手机上如何更新

1. 在旧 App 打开「我的 → 应用更新」，先记下当前安装版本。
2. 如果先出现「体验更新」，下载并点「重新打开并应用更新」，再检查一次。更早的版本没有入口时，联网打开 App，稍后完全退出并重新打开，以获取兼容更新入口。
3. 出现 1.0.9 后点「下载并更新」，在系统下载完成后确认安装。**覆盖安装，不先卸载，不清除应用数据。** 如系统要求，允许此次下载来源安装应用。
4. 回到「应用更新」，确认显示 **1.0.9（11）**。单纯下载体验更新而仍显示 1.0.8，不算完成原生升级。
