最后核对：2026-09-21。数据库、兼容服务端和网页已发布；Android 1.0.8 build 10 可下载安装。系统桌宠仍须完成真机验收，不能把构建或网页检查视为整版验收通过。

## 已锁定的产品决定

- 消息负责聊天与群工具；异宠负责陪伴、记忆、性格成长与桌宠；事项负责唯一任务/目标/提醒详情；我的负责账号、外观、通知与隐私。默认进入陪伴。
- 沿用商务简洁、深浅主题、自定义背景。取消重复消息管家/Agent入口，保留旧路由兼容。
- 安卓和 Windows 首批；透明动态 2D 桌宠，安静停在拖放处，点击小聊，可隐藏/恢复/停止，默认关闭且不自启。手机需真实系统悬浮，电脑需独立程序。
- 性格逐渐接近主人但保留底色，私聊更贴近、群内适度收敛；只学习本人私聊与已授权群内本人表达。跨 3 天至少 5 条有效依据，按日限权，每日最多一次长期更新。外形沿用现有机制。
- 每只异宠分别理解群关系；主人绑定是账号事实，原话/转述/猜测分开，猜测与冲突待确认。群关系学习独立授权。
- 保留请求去重、记忆版本保护、忘记排除、权限隔离及已有原始资产。模型复查与浏览器预览不是设备验收。

## 关键验收

1. 头像重进群不反复空白，跨账号/离群/版本变更正确；异宠消息和 @ 列表使用本体。
2. 已看消息退出不复红，新消息不误清；历史浏览/断网/双设备/同时间消息正确。
3. 连发、媒体、跨群、切页、断网恢复不丢草稿、不重复；服务端回执不等 AI。
4. 同名、改名、冒认主人与询问主人正确；关系纠错/撤回停止相关来源。
5. 长期表达塑造性格但单次情绪不突变；暂停/纠正/恢复/忘记生效，私人证据不传群模型。
6. 四模块入口唯一且操作可达，深浅主题、背景、大小字号与键盘通过。
7. 安卓离开 App 后真实悬浮与小聊；权限撤回/锁屏/账号变化/进程恢复正确。
8. Windows安装、托盘、透明穿透、多屏与缩放、会话同步正确。

性能分别记录 tap/persist/RPC/ACK/Realtime 与 AI；操作反馈目标100ms，热头像500ms，报告同设备网络的 P50/P95，不承诺未经测量的远端耗时。

发布：A独立验收可先发；数据库 → 兼容服务端 → 客户端。原生变化发布新APK/runtime，不投放旧运行时OTA。未获设备实测不能标记D完成。
