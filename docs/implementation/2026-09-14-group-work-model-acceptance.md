## 最终场景结果

| 场景 | 实际结果 | 模型用时 |
| --- | --- | --- |
| 无全员同意 | 无批次、0 次模型调用 | — |
| 明确行动与责任 | 忌口整理与订桌形成 2 个建议，各保留本人的责任原话；提交成功，正式事项数为 0 | 8.528 秒 |
| 玩笑 | 火星开会讨论返回空数组；无建议或正式事项 | 3.257 秒 |
| 假设与愿望 | 包海岛年会的假设返回空数组 | 3.093 秒 |
| 后文取消 | 后文暴雨取消骑行优先于前面的查路线提议，返回空数组 | 3.529 秒 |
| 混合讨论 | 场地确认与带两筒球分成 2 个建议；不包含建体育馆玩笑或已取消爬山 | 17.373 秒 |
| 生成时继续讨论 | 模型产生 1 个初始建议，真实提交返回 `false`；旧范围并入新批次，静默时间重置，未写入提前建议 | 7.689 秒 |
| 生成时撤回同意 | 模型产生 1 个初始建议，真实提交返回 `false`；授权版本失效，后续消息不再注册分析，无建议或事项写入 | 7.683 秒 |

所有非空模型结果都通过精确源消息 ID 与连续原文检查。正常提交的建议数与模型输出一致；未发生用户接受操作，因此没有自动创建正式事项。
