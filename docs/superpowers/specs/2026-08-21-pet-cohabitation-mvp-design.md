# 异宠共生关系空间 MVP 设计

日期：2026-08-21

## 产品定位

这是一款由成长型异宠 Agent 驱动的熟人私人沟通应用，面向不能经常见面的恋人、好友与 3–8 人密友圈。首版允许 16 岁以上用户注册，内容全年龄友好；不提供陌生人发现、公开动态、办公协作、支付或文件传输。

每个用户终身只有一只异宠。同一只异宠陪主人进入全部关系空间，拥有稳定身份与全局成长；进入群聊时只能使用该空间的隔离记忆。每个关系空间另有公共主 Agent，负责客观摘要、待办、规划与游戏主持。

## MVP 体验

### 首页

首页是双核心总览，同时展示异宠状态、关系空间动态、待确认代理事项和“今晚碰个面”。

### 唯一异宠

- 命名、初次对话与生命种子共同决定初始身份，不允许刷初始、换宠或购买第二只。
- 异宠不会死亡、饥饿、退化或责怪主人；离线时继续生活，重逢时表达想念。
- 培养来自相处、示范、纠正、做事与社交，不显示经验条、饥饿值或亲密度。
- 主人可设置作息与主动频率，但异宠保留接受或拒绝互动的自主性。

### 生成式连续进化

- 名字、眼睛、核心色、声音、主要轮廓与标志器官是永久身份锚点。
- AI 只能基于上一形态增量进化；每个变化必须对应可追溯的生命经历。
- 重大进化前主人只能表达期待、祝福或赠送象征物，异宠自主决定结果。
- MVP 展示孵化、一次局部成长和一次重大进化。

### 记忆与空间隔离

- 独处时异宠可使用全局个人记忆；进入空间后只能读取该空间记忆舱与非事件性的安全身份特征。
- 跨空间只同步抽象能力变化，不能泄露其他空间的人物、事件或对话。
- 自动记忆必须展示来源、时间，并允许主人修改或删除。
- 空间成员可以查询主人曾在本空间公开的非敏感信息；健康、住址、财务、情绪低谷等需要主人再次授权。

### 离线共生与宠物角

- 主人离线时，异宠可低频参与相关群聊；所有发言明确标记为异宠内容。
- 纯异宠聊天、互相照顾和短游戏进入宠物角，仅将高光带回主聊天。
- 其他成员可以聊天、投喂、赠送小物和临时照顾，但不能修改身份、查看全局记忆或决定重大进化。
- 主人回来后可查看生命日记，并询问异宠的主观回顾。

### 代理与空间主 Agent

异宠可接受游戏、代填已知偏好、完成轻量投票、创建暂定提醒/日程/待办，并以“我猜主人可能会”回答低风险问题。真实见面、长期计划、情感承诺、关系变化、位置、消费、财务、健康与敏感授权必须等待主人确认。

空间主 Agent 在成员久未上线、讨论形成计划、收到明确请求或到约定回顾时间时工作。它负责客观摘要、待办、共同规划与游戏主持，区分“已确认”“Agent 建议”“待本人确认”，不把异宠发言当作主人承诺。

### 聊天与趣味

- 支持恋人双人、好友双人和 3–8 人密友圈。
- MVP 原型提供文字聊天、引用、心情与沟通意图；图片和短语音通过演示卡表达接口边界。
- “今晚碰个面”由空间成员共同设置时间、频率与时区，由异宠邀请。
- 共同造游戏保留同题揭晓、猜测选择和接力三种安全组件，由人和异宠提供素材、空间主 Agent 主持。

## 信任模型

- 主 Agent 与异宠是明确列出的受限加密成员，权限、消息、代办与记忆来源可查看和撤销。
- 原型实现空间权限与记忆隔离规则，不宣称已实现生产级端到端加密或机密云执行。
- 主人决定异宠人格与代理范围；空间共同决定活跃时段。任一成员可本地静音，过半成员可暂停某只异宠主动发言。
- 跨空间泄露、敏感信息越权披露和重大事项越权承诺均为发布阻断问题。

## MVP 交付边界

本仓库交付可在 iOS、Android 与 Web 运行的 Expo/React Native 纵向原型：完整呈现双核心首页、关系空间、唯一异宠、空间记忆隔离、宠物角、主 Agent、低风险代理、连续进化和精简游戏。Agent 使用确定性本地模拟器，所有生产云端接口通过边界类型隔离。

不在本次实现中伪造：真实云端自治运行、生产端到端加密、后台推送、音视频基础设施、公开宠物社交、任意代码游戏、付费系统和真实图像模型调用。

## 商业边界

测试期免费。未来采用个人守护者会员，可扩展生成额度、记忆容量、栖息地主题、高级 Agent 能力和游戏组件；异宠基础生命、照顾、聊天、空间加入/退出、历史访问和数据导出永久免费。不得收费维持异宠健康、避免死亡、购买第二只异宠或直接购买进化结果。

## 验收

1. 同一异宠进入多个空间时保持身份一致，具体空间记忆不串联。
2. 模拟主人离线后，异宠能参与、接受照顾并生成生命日记。
3. 主 Agent 输出客观摘要，异宠输出主观回顾，两者视觉和数据类型不同。
4. 低风险代办可确认或撤回；重大事项被策略层拒绝。
5. 他人能照顾异宠，但不能改身份、全局记忆和重大进化。
6. 主人只表达期待，进化结果仍由异宠根据经历决定，并保留身份锚点。
7. 长期缺席不会触发死亡、退化、指责或惩罚。
8. 成员可静音或暂停 Agent，不影响人类聊天。
