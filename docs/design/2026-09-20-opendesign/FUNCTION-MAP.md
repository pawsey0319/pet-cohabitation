# 异宠 · 功能地图

本表对照原型里「用户能点什么」和「演示到哪一步」。全部为合成数据。

## 底栏

| 入口 | 默认页 | 用户可完成的事 |
| --- | --- | --- |
| 消息 | 会话列表 | 搜索、进群、建群 |
| 异宠 | 陪伴 | 对话、接续、记忆、性格、关系、桌宠、相处风格 |
| 事项 | 事项列表 | 筛选、打开统一详情、确认/重试/推进阶段 |
| 我的 | 个人主页 | 资料、主题、背景、通知、隐私、导出、退出 |

取消：独立消息管家、主 Agent 工作台作为一级入口。查群办事在陪伴里问异宠；任务详情只在事项。

## 消息

| 界面 | 操作 | 状态 |
| --- | --- | --- |
| 会话列表 | 搜索、点进群、新建群聊 | 空搜索、加载、离线横幅 |
| 群聊 | 发文本；可选「图片（演示）」 | 气泡即刻出现；保存中 → 发送中 → 已发送 / 失败可改草稿重试 |
| 群聊 · 呼唤异宠 | 消息含「@小陶」或「小陶，」 | 先完成发送状态，再显示异宠头像的「正在写」；异宠气泡用宠物头像 |
| 群聊 · 未呼唤 | 普通群消息 | 不出现 AI 等待、不插入异宠回复 |
| 群管理 | 资料、成员、邀请、助手、群工具 | 群工具跳转到事项并带上该群筛选 |
| 邀请 | 多选成员、确认 | 只写一条系统消息，不发网络 |

输入条右侧只有发送；没有「把任务交给 Agent」等工具按钮。

## 异宠

| 界面 | 操作 | 状态 |
| --- | --- | --- |
| 陪伴 | 发送、新话题、继续/收起接续、查看依据 | 空会话、倾听、回复中、失败、长对话、输入聚焦缩小形象 |
| 记忆 | 重要、纠正、忘记、来源、手工增改 | 提取失败横幅；纠正后仍可继续当前话题 |
| 成长 | 看底色与变化时间、暂停学习、纠正习惯、恢复初始 | 暂停后新对话不引用新习惯；恢复需确认 |
| 相处风格 | 短回复 / 先结构 / 不催促 | 立即改变后续陪伴回复口吻（演示） |
| 群关系 | 切换状态说明、开关授权 | 每宠一份；主人绑定账号；猜测/转述/确定 |
| 桌宠设置 | 开启（需权限）、大小、停止 | 默认关；无权限不能开；文案写明不自启不催回 |
| 未确认异宠 | 期待 → 生成 → 预览 → 确认 | 仅工具栏进入，不覆盖已确认默认宠物 |

## 事项

| 界面 | 操作 | 状态 |
| --- | --- | --- |
| 列表 | 筛选 全部/个人/群/目标/提醒/待确认 | 空、加载骨架、错误重试、离线只读 |
| 详情 | 看阶段与进度、标记完成、重试、确认/驳回、推迟提醒 | 进行中 / 失败 / 已完成 / 待确认 |

目标用阶段条（`--v` / `--max` 计算宽度），不手写百分比。

## 我的

| 界面 | 操作 |
| --- | --- |
| 主页 | 进资料、外观、背景、通知、隐私、导出、设置 |
| 外观 | 跟随系统 / 浅 / 深、减少动态 |
| 聊天背景 | 推荐、本地图片裁切暗度、AI 候选（演示效果） |
| 通知 | 会话通知、事项提醒；异宠催回与桌宠自启为关闭且不可用作骚扰开关 |
| 账号 | 登录注册校验、退出、注销（回到登录，不删数据） |

## 桌宠演示层（非产品页）

| 操作 | 表现 |
| --- | --- |
| 拖拽 | 宠物在桌面层内移动，无白底卡片 |
| 点击 | 打开约 240px 小聊天窗，可发一句演示回复 |
| 隐藏 / 恢复 | 隐藏后角落一枚恢复；不是全屏空白 |
| 停止 | 桌面层清空，设置回到关闭 |
| 大小 | 小 / 中 / 大 |
| 权限 | 申请中 / 允许 / 拒绝 |
| 锁屏 | 宠物隐藏 |
| 离线 | 形象仍在，状态为离线，不主动说话 |
| 账号变化 | 停止并提示 |

## 明确不是本原型的能力

自动记忆提取、真实模型、云端并发、系统叠加层/透明窗口、相册上传、付费出图、真实邀请与注销。
