## 必须保留的交互和数据约束

- 短对话输入区紧跟上下文；长对话滚动后输入与发送仍可见。保留现有键盘适配，不把网页 `visualViewport` 代码直接搬进 React Native。
- `PetCompanionPanel` 的 `onSend(content, requestId)`、草稿、请求回复关联继续使用。
- `PreferenceAction.action` 的 `important` / `positive` / `negative` / `retract` / `forget` 继续对应记忆纠正，不合并成删除。
- 手工记忆 20×400；只有主动开启新话题才改边界。
- 个人偏好不传入群聊模型载荷。群关系是「该宠物对该群」的理解，需单独授权，不能默认引用未授权成员。
- 桌宠：默认关闭；不自启；不在通知里催用户打开。权限被拒时保持关闭。
