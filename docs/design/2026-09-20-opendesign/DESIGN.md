# 异宠 · 设计规范

成年用户的日常陪伴产品。界面气质靠近清爽、整齐、略偏商务的即时通讯，但不是微信，也不使用其品牌、Logo 或标志性布局。本原型在 OpenDesign **Neutral Modern** 令牌合同上实现：表面、字号、间距、圆角、海拔沿用该系统；强调色按产品简报从钴蓝改绑为陶土。

## 令牌

`:root` 先粘贴 Neutral Modern 合同，再做产品覆写。组件只引用 `var(--*)`，不在规则里写死十六进制（主题块与演示画布除外）。

### 浅色（默认）

| 角色 | 令牌 | 值 | 用途 |
| --- | --- | --- | --- |
| 背景 | `--bg` | `#fafafa` | 列表、设置、陪伴浅底 |
| 表面 | `--surface` | `#ffffff` | 气泡底、卡片、弹层、输入条 |
| 主文字 | `--fg` | `#111111` | 标题、正文、选中标签 |
| 次文字 | `--muted` | `#6b6b6b` | 时间、摘要、说明 |
| 描边 | `--border` | `#e5e5e5` | 分割、输入框、卡片 |
| 强调 | `--accent` | `#a3563c` | 主按钮、发送、当前会话标记。用户简报覆写，原系统为 `#2f6feb` |
| 强调上的字 | `--accent-on` | `#ffffff` | 主按钮标签 |
| 成功 / 警告 / 危险 | `--success` `#17a34a` · `--warn` `#eab308` · `--danger` `#dc2626` | 状态，不装饰 |

衍生：`--accent-hover` / `--accent-active` 用 `color-mix` 向黑混合 8% / 14%。用户气泡不用纯强调色，而用 `color-mix(in oklab, var(--accent) 14%, var(--surface))`，保证 16px 正文对比度 ≥ 4.5:1。

一屏强调色最多两处：通常是发送键或一枚未读标记，选中底栏用 `--fg` 而不是强调色。

### 深色（不是浅色反相）

暖炭而不是纯黑：`--bg #141312`，`--surface #1c1b1a`，`--fg #f0eeeb`，`--muted #a3a09a`，描边为白 10% 透明。强调略提亮为 `#c17a5c`，按钮文字使用 `#171310`，避免陶土在深底上发闷并保持对比。气泡与输入条跟表面走，不把浅色块原样反白。

### 字体

- Display / Body：`"Inter", "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei", system-ui, sans-serif`
- Mono：`ui-monospace, "JetBrains Mono", monospace`（字数统计、演示账号、发送状态）
- 中文正文 16–17px，行高 1.7；标题行高 1.35，字距 0（CJK 不负 tracking）
- 三档字重：400 阅读、550 控件、600 标题与主按钮
- 一屏可见字号不超过三档。演示「大号」只把正文抬到 18px，不另开字体。

### 间距与圆角

4px 网格。触控目标 48px。按钮/输入 `--radius-sm: 8px`，卡片/弹层 `--radius-md: 12px`。不用巨大圆角堆叠，不用胶囊卡片墙。

### 海拔

默认平。下拉、对话框、浮动操作才用 `--elev-raised`。输入框无投影。不做毛玻璃、新拟态。桌宠小窗用 raised，宠物本体无底框。

### 动效

`--motion-fast 150ms` / `--motion-base 200ms`，`cubic-bezier(0.2, 0, 0, 1)`。异宠仅轻微呼吸与轻晃。`prefers-reduced-motion` 与设置里的「减少动态」同时关闭呼吸、轻晃与过渡。

## 布局

- 产品画布默认 390px 宽，适配 320 / 360 / 430，禁止横向溢出。
- 桌面：画布居中；左侧为**原型工具**，不进入手机产品界面。开启桌宠演示时，宽屏在画布旁放一块标明「演示」的桌面层，不把宠物塞进满屏白卡片。
- 底栏四入口：**消息 / 异宠 / 事项 / 我的**。默认 **异宠 → 陪伴**。选中项用字重与前景色，不用强调色填满。
- 异宠分区：陪伴 / 记忆 / 成长 / 桌宠。相处风格、群关系从成长或陪伴「更多」进入，不进「我的」。
- 陪伴列：顶栏 → 克制形象 → 近期接续 → 对话 → **紧随对话的输入区**。短对话不把输入条钉死在屏幕底部留白；长对话在滚动容器内 `position: sticky; bottom: 0`。
- 群聊输入旁只保留消息操作（发送、可选本地图片演示）。成员、邀请、资料、助手、任务入口全部收在群管理。
- 聊天背景只作用于对话卷轴与配套气泡/文字，不影响底栏、列表、设置。
- 桌宠形象：透明 2D SVG，无白色底板。默认安静；点击出小聊天窗（约 240px），不要变成第二块全屏应用。

## 一条视觉主张

陶土小兽（透明 SVG 占位）+ 用户气泡一层薄暖色。其余保持纸面一样的平面与对齐。正式版形象按交接文档替换为用户现有宠物，不在本原型假装已有品牌 IP。

性格底色用一条由陶土到青灰的克制渐变条表示偏移，旁边写依据与时间，不当作装饰彩虹。

## 明确不做

- 恋爱等级、签到、共同养宠、孵化五轮
- 通知铃铛
- 独立「消息管家」入口
- Emoji 当图标；巨大装饰头像；渐变大标题；满屏白框桌宠
- 向用户展示记忆漂移分数
- 把「最近喝茶」写成「讨厌咖啡」
- 为聊天背景接真实图片模型或上传服务
- 桌宠默认开启、自启或催回

## 无障碍

可见 `:focus-visible` 使用 `--focus-ring`。表单必有 `label`。正文对比目标 4.5:1。图标 1.7px 描边、`currentColor`。聊天背景预览里若遮罩过浅，提示加深，不静默降低对比。桌宠小窗保持文字对比，不把字直接叠在桌面上。
