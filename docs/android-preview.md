# Android 第一轮内测

## 这是什么版本

仅供少量熟人使用的 Android 测试 APK，包名 `com.pawsey.petcohabitation`，支持 `arm64-v8a` 手机。它连接现有云端数据，与[网页版](https://pet-cohabitation-public.vercel.app)共用账号、群聊和异宠。

GitHub Actions 备用包使用调试签名，不是商店正式版。当前没有配置 FCM，不能依赖系统通知栏提醒；应用内通知收件箱及聊天历史仍保存在云端。iPhone 本轮继续使用手机浏览器，不安装此 APK。

## 安装和邀请

1. 只安装本项目提供的 APK，按手机提示允许当前下载/文件应用安装；不要安装来历不明的同名包。
2. 打开“异宠共生空间”，使用已有邮箱、密码登录；新用户先向管理员领取单次注册邀请码。
3. 在聊天页“更多功能”中创建空间邀请，分享正式 HTTPS 地址。
4. 对方打开链接，在网页登录并接受空间邀请；再用相同账号打开 App，群聊会同步出现。当前不承诺网页邀请能自动唤起 App。

注册邀请码与空间邀请链接不是一回事：前者用来创建账号，后者让已有账号进入某个群。

## 两台设备优先测试这六项

1. 甲用 APK、乙用另一个账号的手机浏览器，在同群互发文字；看双方是否实时收到。
2. 连续发送、查看历史时发送、收起/弹出软键盘；最新气泡应可见，输入栏不得被遮住。
3. 发送一张图片和一段短语音，另一台设备打开图片、播放语音；拒绝权限后应有提示且文字聊天仍可用。
4. 甲断网发送一条文字，恢复网络后只出现一次；杀进程再打开检查登录与待发送消息恢复。
5. 在主 Agent 面板发起有明确时间的日程，乙看到聊天卡片并投票；异宠查询已读历史应给出真实内容和来源。
6. 退到后台数分钟再打开，聊天、任务状态和应用内通知应恢复。系统推送暂不作为本包通过项。

## AI 的运行条件

云端基础聊天不依赖开发者电脑；异宠文本/图像仍依赖开发者电脑、CPA 和 Cloudflare Tunnel 在线。AI 离线时应明确显示失败或暂不可用，不应返回假回复，也不应阻断人类聊天。

## 反馈时提供

手机型号、Android 版本、网络类型、操作步骤及截图即可；不要提供密码、API Key 或完整私人聊天记录。APK 安装成功不等于全部真机验收通过，以上项目需记录实际结果后才能扩量。
