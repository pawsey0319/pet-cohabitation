# Demo 验收清单

## 自动化结果

2026-09-03 本轮已验证（真实 CPA，不是 Mock）：

- Jest：31 个测试套件、214 个测试通过；TypeScript 通过。
- 原生邀请地址回归：Android/iOS 使用正式站点配置；缺失、占位、本机或包含凭据的地址被拒绝，Web 仍使用当前页面来源。
- 原生媒体适配回归：使用设备文件系统读取图片/录音并以 ArrayBuffer 上传，拒绝丢失、空白和超限文件；Web 保留 Blob 上传。单测不替代真实相册、录音和存储权限测试。
- 公网 Playwright：两条用例连续通过，包括邀请入群、实时文字、发送后滚动、历史阅读位置、引用回复、表情、私有图片预览、主 Agent 简报、日程卡片与投票，以及异宠期待设定、真实首图、确认锁、历史回忆来源、投喂和玩耍。
- Pixel 7 浏览器仿真：双账号聊天/简报/日程/图片用例通过。它验证手机 Web 布局，不等价于 Android 真机验收。
- 云端通知集成：收件人隔离、标记已读权限、客户端不能伪造通知、唯一 outbox、通知偏好、群静音、非成员拒绝均通过；仅创建并清理测试账号/空间，没有向真实设备发送通知。
- 结构化模型回归：识别 `finish_reason=length`，拒绝半截 JSON 和无关对象，格式修复最多重试一次，错误日志不保存模型原文。
- 云端 125 条未读合成消息简报通过，首尾话题均保留、计数正确，本次总耗时约 9.3 秒（单次冒烟，不代表 p95 指标）。
- 已读消息回忆与 Realtime 阶段状态通过：`queued → classifying → retrieving → thinking → succeeded`；重试同一请求仅保留一条主人消息和一条回复。

原有邀请码/人数上限/RLS/账号注销等集成脚本仍保留，但不能将历史通过结果当作本轮重新验证。APK 安装、系统软键盘、录音权限、后台恢复和 FCM 推送须在真实手机单独验收。

## 手工产品验收

### 聊天

1. 两个隐私窗口分别登录，在双人空间互发文字，刷新后历史仍在。
2. 断网发送应显示失败；恢复网络并重试后，同一 `client_id` 只出现一次。
3. 图片超过 8 MB、语音超过 60 秒或 5 MB 应在客户端/Storage 规则处失败。
4. 非空间成员使用 API 查询消息、回应或媒体，应得到空结果或拒绝。
5. 群空间第 20 人成功，第 21 人由数据库拒绝；双人空间第 3 人拒绝。

### 异宠

1. 初次使用填写名字、外观、性格、相处方式等期待即可生成，不要求五轮孵化对话；确认前可以改图、切换候选或重新探索。
2. 二次确认后，页面不再显示初始编辑；直接调用候选 API 或改回 `incubating` 也会被服务端拒绝/回正。
3. 纠正札记后显示纠正文本；忘记后该信号从活跃列表消失且不再进入 prompt。
4. 确认后的新相处才能开启下一次进化；正式资产记录父图和事件。
5. 报告完全断裂只允许用同一父图和事件修复一次，不能输入新造型要求，也不能恢复历史候选。

### 多人空间与 Agent

1. 未全员同意时，“观察授权”显示暂停；全员同意后只分析异宠主人未来的发言。
2. 新成员加入后所有旧同意失效，必须由当前全体成员重新同意。
3. `@异宠名` 或回复异宠会创建任务；普通消息不触发主 Agent，也不触发异宠隐式插话。
4. 主人 5 分钟内在线时，异宠不代答主人问题；见面、承诺、关系、立场、位置、健康、消费和财务始终等待本人。
5. 宠物角的陪伴、投喂和玩耍只生成角落故事；只有点击“分享到主聊天”才进入聊天流。
6. 成员从独立主 Agent 面板提出需求，简报区分已确认、建议和待本人确认；日程提案进入主聊天并可投票，异宠消息不被当作主人的正式承诺。
7. 任一成员的“仅我静音”不影响他人；暂停票只有超过当前成员半数才停止该异宠，且人类消息继续正常发送。
8. 离开候选或进化页面再返回，原任务继续显示“排队中 / 生成中 / 已完成 / 失败”；重复点击或刷新不产生第二个正式结果。

### 管理、隐私与发布

1. 管理员状态页只出现数量、成功率、耗时、错误码和聚合反馈，不出现消息正文或单条反馈人身份。
2. 暂停图像或隐式回应后，人类聊天仍正常；恢复开关后只影响后续任务。
3. 导出 JSON 只含当前用户的资料、本人消息、异宠档案和成长记录。
4. 注销必须重新验证密码；私聊、草稿和媒体删除，空间中的本人消息正文匿名化。
5. 配置测试结束时间和 30 天保留期后，定时清理只删除非管理员测试账号。
6. 正式网址分别使用电信、联通和移动网络验证登录、聊天、Realtime、媒体和模型任务；两家以上无法访问则停止扩量。

## 发布阻断项

出现以下任一情况不得发布测试网址：

- 跨空间具体人物、事件或对话泄露。
- 未经全员同意分析空间对话，或给其他成员建立画像。
- 非成员读取私聊、草稿、消息或私有媒体。
- 确认后重新捏宠、恢复历史候选或产生两个同事件正式结果。
- 异宠越权确认见面、关系承诺、冲突立场、位置、健康或财务事项。
- Service Role 或模型密钥进入前端 bundle、Git 提交或 Vercel 公共环境变量。
