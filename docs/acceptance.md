# Demo 验收清单

## 自动化结果

- Jest：15 个测试套件、147 个测试。
- Supabase 集成：邀请码单次使用、双人/20 人边界、RLS、聊天约束、确认锁、观察共识、多宠路由、宠物角、札记反馈、进化连续性、新成员暂停观察、原子额度。
- Playwright：两个独立浏览器账号完成邀请、实时聊天、回复、回应和主 Agent 摘要；主人完成孵化、确认、确认后相处、重大进化和一次连续性修复。
- TypeScript、Expo 依赖检查、数据库 lint 和 Web 静态导出。

## 手工产品验收

### 聊天

1. 两个隐私窗口分别登录，在双人空间互发文字，刷新后历史仍在。
2. 断网发送应显示失败；恢复网络并重试后，同一 `client_id` 只出现一次。
3. 图片超过 8 MB、语音超过 60 秒或 5 MB 应在客户端/Storage 规则处失败。
4. 非空间成员使用 API 查询消息、回应或媒体，应得到空结果或拒绝。
5. 群空间第 20 人成功，第 21 人由数据库拒绝；双人空间第 3 人拒绝。

### 异宠

1. 少于 5 轮不能生成候选；确认前可以连续改图、切换候选或重新探索。
2. 二次确认后，页面不再显示初始编辑；直接调用候选 API 或改回 `incubating` 也会被服务端拒绝/回正。
3. 纠正札记后显示纠正文本；忘记后该信号从活跃列表消失且不再进入 prompt。
4. 确认后的新相处才能开启下一次进化；正式资产记录父图和事件。
5. 报告完全断裂只允许用同一父图和事件修复一次，不能输入新造型要求，也不能恢复历史候选。

### 多人空间与 Agent

1. 未全员同意时，“观察授权”显示暂停；全员同意后只分析异宠主人未来的发言。
2. 新成员加入后所有旧同意失效，必须由当前全体成员重新同意。
3. `@异宠名` 或回复异宠会创建任务；无关消息保持静默。隐式消息最多一只异宠回复，显式最多三只。
4. 主人 5 分钟内在线时，异宠不代答主人问题；见面、承诺、关系、立场、位置、健康、消费和财务始终等待本人。
5. 宠物角的陪伴、投喂和玩耍只生成角落故事；只有点击“分享到主聊天”才进入聊天流。
6. 主 Agent 摘要明确显示已确认、建议和待本人确认，异宠消息不被当作主人的正式承诺。
7. 任一成员的“仅我静音”不影响他人；暂停票只有超过当前成员半数才停止该异宠，且人类消息继续正常发送。

## 发布阻断项

出现以下任一情况不得发布测试网址：

- 跨空间具体人物、事件或对话泄露。
- 未经全员同意分析空间对话，或给其他成员建立画像。
- 非成员读取私聊、草稿、消息或私有媒体。
- 确认后重新捏宠、恢复历史候选或产生两个同事件正式结果。
- 异宠越权确认见面、关系承诺、冲突立场、位置、健康或财务事项。
- Service Role 或模型密钥进入前端 bundle、Git 提交或 Vercel 公共环境变量。
