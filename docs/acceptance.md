## 手工产品验收

### 聊天

1. 两个隐私窗口分别登录，在双人空间互发文字，刷新后历史仍在。
2. 断网发送应显示失败；恢复网络并重试后，同一 `client_id` 只出现一次。
3. 图片超过 8 MB、语音超过 60 秒或 5 MB 应在客户端/Storage 规则处失败。
4. 非空间成员使用 API 查询消息、回应或媒体，应得到空结果或拒绝。
5. 群空间第 20 人成功，第 21 人由数据库拒绝；双人空间第 3 人拒绝。

### 异宠

1. 少于 5 轮不能生成候选；确认前可以连续改图、切换候选或重新探索。
2. 二次确认后，页面不再显示初始编辑；直接调用候选 API 或改回 `incubating` 也会被服务端拒绝/回正。
3. 纠正札记后显示纠正文本；忘记后该信号从活跃列表消失且不再进入 prompt。
4. 确认后的新相处才能开启下一次进化；正式资产记录父图和事件。
5. 报告完全断裂只允许用同一父图和事件修复一次，不能输入新造型要求，也不能恢复历史候选。

### 多人空间与 Agent

1. 未全员同意时，“观察授权”显示暂停；全员同意后只分析异宠主人未来的发言。
2. 新成员加入后所有旧同意失效，必须由当前全体成员重新同意。
3. `@异宠名` 或回复异宠会创建任务；无关消息保持静默。隐式消息最多一只异宠回复，显式最多三只。
4. 主人 5 分钟内在线时，异宠不代答主人问题；见面、承诺、关系、立场、位置、健康、消费和财务始终等待本人。
5. 宠物角的陪伴、投喂和玩耍只生成角落故事；只有点击“分享到主聊天”才进入聊天流。
6. 主 Agent 摘要明确显示已确认、建议和待本人确认，异宠消息不被当作主人的正式承诺。
7. 任一成员的“仅我静音”不影响他人；暂停票只有超过当前成员半数才停止该异宠，且人类消息继续正常发送。
8. 离开候选或进化页面再返回，原任务继续显示“排队中 / 生成中 / 已完成 / 失败”；重复点击或刷新不产生第二个正式结果。

### 管理、隐私与发布

1. 管理员状态页只出现数量、成功率、耗时、错误码和聚合反馈，不出现消息正文或单条反馈人身份。
2. 暂停图像或隐式回应后，人类聊天仍正常；恢复开关后只影响后续任务。
3. 导出 JSON 只含当前用户的资料、本人消息、异宠档案和成长记录。
4. 注销必须重新验证密码；私聊、草稿和媒体删除，空间中的本人消息正文匿名化。
5. 配置测试结束时间和 30 天保留期后，定时清理只删除非管理员测试账号。
6. 正式网址分别使用电信、联通和移动网络验证登录、聊天、Realtime、媒体和模型任务；两家以上无法访问则停止扩量。

## 个人陪伴增量（2026-09-07）

1. 异宠页先呈现私聊；第五轮之后继续发送，不反复输出第五条孵化提示。Enter 发送、忙碌禁用和失败保留草稿可用。
2. 本人私聊可选取并改写后保存记忆；手工添加、编辑、移出可用。满 20 条后拒绝新增、仍能编辑或移出；超 400 字可在编辑器中缩短后继续。
3. 主人以外的用户不能读写个人记忆或上下文状态；不能以他人私聊、异宠回复或群消息 ID 作为记忆来源；新增记忆不进入群发言和进化模型载荷。
4. 修改“喜欢咖啡”为“喜欢茶”保留变化历史，不结束当前话题；明确“不再喜欢”停止当前推荐，未来明确恢复可更新；“从没喜欢”作为纠错使错误依据无效，不能描述成真实过去。
5. 模型生成期间在另一客户端编辑/移出记忆或开始新话题，旧回复不能写回。前端保留输入和请求标识；重试及刷新重试不重复写主人消息。真实 Realtime 跨客户端更新仍需完整联调。
6. 跨 6 小时返回有当前段私聊记录的页面，只显示真实主人原句及时间，不新增聊天或调用模型。无有效来源不造故事。普通“你记得我的偏好吗”不能触发群消息检索。
7. 接续按钮只填草稿；新话题经确认后收起旧接续，保留长期记忆；刷新后仍遵守该边界。
8. 导出包含本人手工记忆、版本、偏好依据、重要标记和排除来源；注销级联删除。忘记后关联原文、回复及有来源的风格摘要不再使用，后台延迟完成的提取不能恢复；原始聊天和过去成长记录仍可回看。
9. 在 390px 手机和桌面宽度检查可读性、输入、记忆弹窗和滚动，无横向溢出；使用真实文本模型另测倾诉、建议、过时事实、矛盾记忆和纠错响应质量。
10. 自动记忆只接受本人明确表达；朋友、假设、玩笑、问题及从这些语境截短的模型引文不能变成偏好。场景必须在原话中，晚上不喝不能扩大成全局否定。
11. 最近更喜欢茶优先于旧咖啡频次；同对象同一天最多贡献一次，近 90 天累计 5 天达到频次上限；来源重试不重复写证据，手工操作不虚构表达频次。
12. 自动证据与手工额度分开，依据可分页查看，支持当前/过去状态、原话、日期、重要、纠错和忘记。界面不展示小数分数，模型每次最多使用 5 项相关偏好。
13. 提取失败不隐藏已成功的回复；失败任务可由后续聊天或按钮重试。只有用户主动“开启新话题”改变上下文边界，忘记排除受影响来源后仍保留无关的主人发言。

## 发布阻断项

出现以下任一情况不得发布测试网址：

- 跨空间具体人物、事件或对话泄露。
- 未经全员同意分析空间对话，或给其他成员建立画像。
- 非成员读取私聊、草稿、消息或私有媒体。
- 确认后重新捏宠、恢复历史候选或产生两个同事件正式结果。
- 异宠越权确认见面、关系承诺、冲突立场、位置、健康或财务事项。
- Service Role 或模型密钥进入前端 bundle、Git 提交或 Vercel 公共环境变量。
