# Android 1.0.4 键盘与模型调用修复

日期：2026-09-08。实现位于 `agent-workbench-pet-onboarding` 工作区；现有 APK 包名为 `com.pawsey.petcohabitation`，versionCode 为 5。

## 问题依据与修复

1. 群聊原来只为 iOS 设置键盘避让。异宠私聊的输入框位于长滚动内容内，主 Agent 表单和历史可能挤出底部输入区。新增通用键盘布局组件，在 Android 使用高度避让；异宠私聊和主 Agent 输入区固定在滚动内容下方；滚动表单在键盘出现、焦点或输入尺寸变化时展示当前输入框。
2. CPA 模型目录返回 HTTP 200，但实际 `opencode-glm-5.3` 请求返回 HTTP 400，错误类型为 `MissingSessionID`。去掉可选推理参数仍失败；经同一网关调用已配置的 `glm-5.3` 能返回有效结构化内容。此次使用有效路由，没有通过伪造客户端身份规避限制。
3. 旧健康检查仅验证目录接口，客户端在检查失败后还会读取过去的成功记录。现在文本检查走实际模型适配器并验证结构化输出；图片状态只表示模型目录可达；调用失败、请求过期和账号切换不会继续显示旧成功结果。健康检查有调用额度限制。
