# 异宠 · 全 App 视觉重设计

日期：2026-09-10。OpenDesign + Grok Build `grok-4.6` 生成设计，Codex 完成浏览器检查、修正和现有安卓代码对接说明。

## 打开

- 双击本目录的 `index.html`，无需安装依赖或构建。
- OpenDesign 的“异宠 · 全 App 视觉重设计”项目中打开 `index.html`。
- 宽屏左侧是原型工具，可切换 360 / 390 / 430px、长对话、失败、提取失败、首次进入、未确认异宠和大字号等场景。
- 手机宽度直接显示应用画布。浅深色切换位于“我的 → 外观”，背景位于“我的 → 聊天背景”；单聊背景位于聊天右上角“更多”。

原型保留消息 / 异宠 / 我的导航，默认陪伴页。包含记忆管理、消息管家、成长、群聊与 Agent、异宠生成确认，以及登录、设置、背景定制等主要流程。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 可点击原型，单文件、无外部资源依赖 |
| `BRIEF.md` | 已确认需求及发送给 Grok 的设计任务 |
| `DESIGN.md` | 风格、深浅色令牌、字体、间距与交互规范 |
| `HANDOFF.md` | 原型页面、演示状态和接入边界 |
| `RN-INTEGRATION.md` | 根据本地安卓源码核对的组件、文件和接口对应 |
| `QUALITY.md`、`verification.json` | 检查范围、结果及未覆盖项 |
| `previews/` | 陪伴、记忆、消息和背景的静态预览 |

本次是视觉原型交付，现有 App 尚未套用新设计。图片留在页面内存，AI 背景使用内置示例；所有账号、聊天、任务和记忆均为演示数据。
