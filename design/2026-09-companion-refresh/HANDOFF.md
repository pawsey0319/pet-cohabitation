# 异宠 · 交接

范围：仅本 OpenDesign 项目里的可点击 HTML 原型。不改现有 App 仓库，不接真实后台，不部署。对话、账号、记忆均为合成演示数据。

主文件：`index.html`（单页，无构建、无 CDN）。配套说明：`DESIGN.md`、本文件。

## 页面与组件

| 路由 | 说明 | 关键状态 |
| --- | --- | --- |
| `companion` | 陪伴。形象、接续、对话、输入 | 短/长对话、倾听、回复中、失败重试、输入聚焦缩小形象、新话题分隔 |
| `memory` | 记忆管理 | 当前理解 / 过去偏好 / 变化依据；重要；纠正；忘记；提取失败横幅 |
| `memory-form` | 新增或编辑 | 最多 20 条、每条 400 字、分类必选 |
| `memory-source` | 查看来源 | 原话、日期、所属条目 |
| `messages` | 消息列表 | 搜索、未读、时间、摘要；无铃铛 |
| `group` | 群聊 | 与陪伴同一套输入/失败；邀请；把任务交给 Agent |
| `invite` | 邀请成员 | 多选、确认（演示，不发网络） |
| `agent` | 主 Agent 工作台 | 任务列表；**不出现个人记忆** |
| `task` | 任务详情 | 进行中 / 失败重试 / 已完成 |
| `steward` | 消息管家 | 功能查询与摘要，设计语言同陪伴，无记忆入口 |
| `growth` | 成长 | 形象、记录、操作；无恋爱等级/签到/共养 |
| `hatch` | 未确认异宠 | 期待 → 生成中 → 失败可重试 → 预览 → 确认。仅演示工具进入，默认不覆盖已确认宠物 |
| `me` | 我的 | 资料、外观、聊天背景、减少动态、隐私、导出、退出/注销 |
| `profile` | 编辑资料 | 本地演示校验 |
| `settings` | 设置汇总 | 链到子页 |
| `appearance` | 跟随系统 / 浅 / 深 | 立即作用到 `data-theme` |
| `privacy` | 隐私说明 | 文案级，无真实采集 |
| `export` | 导出 | 生成本地文本，标明演示 |
| `chat-bg` | 聊天背景 | 默认/推荐、图片、AI；全局或单聊覆盖；仅自己可见 |
| `chat-bg-photo` | 从图片选择 | 本地 FileReader，裁切/位置/暗度，气泡预览后应用，不上传 |
| `chat-bg-ai` | AI 设计 | CSS/SVG 候选，标注「演示效果」 |
| `login` / `register` | 登录注册 | 空值、格式、不一致、提交中、错误 |

对话框（产品内，非桌面工具）：退出登录、注销（不删数据）、忘记记忆、恢复全局背景、新话题确认。

桌面工具栏（非产品）：画布 360/390/430、回复失败、发送中、首次进入、长对话、提取失败、未确认异宠、未登录、大号字体、重置。

## 哪些是演示

- 全部消息、群成员、任务、记忆条目、成长记录
- 发送后的「回复」：本地脚本，延时后插入固定或模板句，失败由工具栏开关触发
- 聊天背景「AI 设计」：三张内置纹理，不调用图片模型
- 图片背景：以 Data URL 保存在当前页面内存，刷新或关闭页面后清除，不上传。全局与单聊应用分别保存图片和裁切参数的快照，编辑未应用的图片不影响已应用背景。
- 导出/注销：不接触磁盘以外的用户数据；注销只回到登录页
- 未确认异宠生成：预置 SVG 色稿

## 现有 RN 对接（建议，不在本原型实现）

| 原型能力 | 建议对接 | 不要新增的原生依赖 |
| --- | --- | --- |
| 底栏 IA | 现有三 Tab 导航 | 不换导航库 |
| 陪伴输入贴紧对话 | 保留现有 `PetCompanionPanel` 与 `KeyboardScreen`。短列表输入紧跟上下文，长列表滚动，沿用当前 Android 1.0.4 键盘适配，不要求改原生清单 | 不引入第三方键盘组件 |
| visualViewport | RN 侧用 Keyboard 事件即可 | — |
| 记忆纠正/忘记 | 原型的 `no_longer` / `never_was` 是展示状态；真实 `PreferenceAction.action` 使用 `negative` / `retract`，恢复使用 `positive`，另有 `important` / `forget`。禁止用漂移分数做 UI | 不新机器学习 SDK |
| 聊天背景 | 全局与 `threadId` 覆盖写入现有本地存储；图片用系统相册/相机取本地 URI，裁切用现有 Image 或已集成裁切；遮罩与气泡色是本地样式变量 | 不接对象存储、不为此加生成式图片 SDK |
| AI 背景 | 若生产暂无模型，保持「即将提供」或沿用现有图片能力；文案必须区分预览与真生成 | 不为本功能新增付费图片 SDK |
| 主题 | 现有 Appearance / 用户设置 | 不引入主题框架 |
| 减少动态 | `AccessibilityInfo.isReduceMotionEnabled` 与设置开关取或 | — |
| 异宠形象 | 正式版替换 SVG 占位为用户已有宠物资源 | 不新 3D/直播 SDK |

后台记忆逻辑本原型只模拟：当前理解、过去偏好、变化依据三层；「最近偏爱茶」不自动写成讨厌咖啡。接入点：读取条目列表、写入纠正、忘记及关联来源排除、手工增改（20×400）、提取失败重试。手工额度与自动依据分开。忘记不能只做列表删除，必须复用现有来源排除、迟到任务处理及版本校验。原型仅针对合成示例演示失效依据停止使用，不具有真实自动提取或云端并发能力。UI 不展示小数分数。

实际源码位置与字段核对见同目录 `RN-INTEGRATION.md`，以该文件及现有源码为准。消息页保留新建群聊入口，创建、邀请均为当前页面内的合成场景，不发送真实邀请。原型中的“重置演示数据”恢复所有示例状态。

## 浏览器检查后的调整

Codex 在 Grok 原稿上修正了窄屏画布、形象与气泡样式冲突、主按钮对比度、失效记忆和接续来源、背景预览与已应用状态隔离、搜索焦点与重试草稿。原型文件已保持与 OpenDesign 项目同步；具体检查记录见 `QUALITY.md`。

## 真机仍需验证

- Android 系统键盘与全面屏手势是否遮挡输入条、发送键
- 360 / 折叠外屏 / 字体放大 1.3 倍时气泡与顶栏是否裁切
- 本地相册选图的 EXIF 旋转与超大图内存
- 深色模式下用户自选亮图 + 低遮罩的真实对比
- TalkBack 对气泡、记忆操作表、底栏的朗读顺序
