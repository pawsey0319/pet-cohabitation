# 异宠共生空间

一个面向恋人、好友和 3–8 人密友圈的本地纵向原型：每位主人只有一只成长型异宠；异宠能进入多个熟人关系空间，但具体人物、事件和对话只保留在各自的空间记忆舱中。

## 产品定位与边界

本原型演示三块界面：双核心首页、关系空间和异宠生命档案。它覆盖空间记忆隔离、离线后的确定性本地模拟、宠物角、空间主 Agent、低风险代理、照顾、记忆编辑/删除与身份锚点不变的渐进进化。

它不提供陌生人发现、公开动态、办公协作、文件传输或支付；内容按 16+、全年龄友好演示。异宠不会死亡、饥饿、退化或责怪长期未上线的主人，也没有经验条、亲密度、换宠、重抽或购买进化结果。

## 架构与本地模拟

这是 Expo 57 + React Native + TypeScript 的本地优先单客户端原型。

- `src/domain/` 是唯一的领域类型、访问/代理策略、进化规则、seed 和确定性 Agent 运行时。
- `src/state/AppState.tsx` 用 reducer 管理状态，并通过 AsyncStorage 以 `pet-cohabitation-mvp-v1` 保存本机演示状态。
- `src/state/selectors.ts` 集中进行当前身份的空间、记忆、代理事项与宠物角可见性过滤。
- `src/screens/` 和 `src/components/` 只通过 provider action 驱动交互；不会直接修改 seed。

所谓“Agent”是确定性本地模拟器，不会联网、调用模型或在应用关闭后运行。离线模拟最多按日期生成有限的异宠消息和宠物角故事；作息使用 ISO/UTC 做可重复计算，尚未有按关系空间建模的真实时区。

`currentUserId` 也是本地演示状态，不是认证凭据，不能被视为不可伪造的当前用户。它只用于演示当前成员可见内容和可执行操作；生产版必须以真实会话和服务端授权替代。

## 运行环境

- Node.js 20 LTS 或更高版本
- npm 10 或更高版本（Node.js 安装包通常自带）

在仓库根目录执行以下精确命令：

```bash
npm install
npm run web
npm test -- --runInBand
npm run typecheck
npm run export:web
```

`npm run web` 启动 Metro 开发服务；终端会输出浏览器地址。`npm run export:web` 会生成本地 `dist/` 静态 Web 导出，`dist/` 不纳入版本控制。

## 390 × 844 演示步骤

1. 启动 `npm run web`，在浏览器开发工具将视口设为 **390 × 844**，打开终端输出的 Web 地址。
2. 首页应同时看到“今天的异宠”“关系空间”“待你确认”“今晚碰个面”四张双核心卡。
3. 点“老友小圈”进入关系空间：时间线应区分人类、异宠和空间主 Agent；展开主 Agent，查看宠物角并点“照顾”，再点“问问异宠”。
4. 在代理事项中，对低风险“暂定提醒”依次点“本人确认”和“撤回”；“真实见面”应显示阻断原因，不能代替主人确认。
5. 点底部“异宠”：查看“可追溯记忆”中的来源/时间/范围，编辑或删除一条自动记忆；输入期待或祝福后提交进化提案，并在 sheet 中只做“接受这次成长”的浅参与，不选择最终形态。
6. 如需返回初始演示状态，在异宠页使用“重置演示”。这会删除本机的原型存档并恢复确定性 seed。

## 隐私、删除与记忆边界

- 具体记忆带有空间 ID、来源与时间。异宠进入空间时仅可读取该空间记忆和非事件性的抽象特征；跨空间的人物、事件和对话应被策略层拒绝。
- 自动记忆可在主人生命档案中编辑或删除；普通成员只能看见其共同空间中允许公开的普通记忆，不能看到全局、主人专属或敏感内容。
- “重置演示”删除本机 AsyncStorage 中的原型键并恢复 seed。仓库没有云端账户、服务端数据库或远端备份，因此也没有云端删除 API、保留期或数据导出承诺。
- 本地浏览器/设备存储不等同于端到端加密；请勿把演示数据当作真实私密通信数据。

## 免费与收费边界

当前原型没有账户、订阅、内购、支付 SDK 或支付流程。产品设想中，异宠的基础生命、照顾、聊天、空间加入/退出、历史访问与数据导出应永久免费；不得对维持健康、避免死亡、第二只异宠或直接购买进化结果收费。任何未来会员能力（如生成额度、记忆容量、主题、高级 Agent 或游戏组件）均未在本仓库实现。

## 已知限制（请勿当作生产能力）

此仓库是 **local vertical prototype**，明确未实现以下能力：

- 云端异宠自主运行、跨设备同步、多用户网络或真实的多人会话；
- 真实认证、不可伪造的 `currentUser` / `currentUserId`，以及生产服务端授权；
- 生产级端到端加密（E2EE）、密钥轮换或机密云执行；
- push 通知；
- 真实图片或语音上传、音视频基础设施与文件传输；
- 真实模型调用、推理、训练、生成式图像或任何模型能力承诺；
- 支付、订阅、内购或订单处理。

此外，作息和离线模拟依赖 UTC 的确定性时间计算，不代表用户所在时区或每个关系空间的真实活跃窗口。该边界是为可测试演示而设，不应直接迁移到生产逻辑。
